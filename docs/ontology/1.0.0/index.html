협동로봇 제조 데이터 관리 온톨로지

Cobot Manufacturing Data Management Ontology

협동로봇(예시: 가상 VORLA 시리즈)의 설계 BOM, CAD 메타데이터, 사양, I/O, 안전 설정, 운영·보전 데이터를 통합 관리하기 위한 OWL 2 스키마. STEP AP214의 PRODUCT / PRODUCT_DEFINITION / NEXT_ASSEMBLY_USAGE_OCCURRENCE 구조와 정렬되어 있다.
