M2 설계 BOM

cmdmsh:ItemDefinitionShape

NodeShape

대상 클래스 cmdm:ItemDefinition

경로조건수준메시지
cmdm:itemCode 최소 1개 · 최대 1개 · 형식 xsd:string 위반 아이템 코드는 정확히 1개여야 합니다.
cmdm:definedInFile 최소 1개 · 클래스 cmdm:CADModelFile 위반 아이템은 정의 CAD 파일을 가져야 합니다.
cmdm:drawingNumber 패턴 ^DW-[0-9]{2}-[0-9]{6}[A-Z]?$ 경고 도면번호 형식은 DW-21-004213B 형태여야 합니다.
cmdm:volume 최대 1개 · 값 > 0 위반
cmdm:partNumber 최소 1개 경고 PLM 품번이 없습니다.

cmdmsh:PartMaterialShape

NodeShape

대상 클래스 cmdm:PartDefinition

경로조건수준메시지
cmdm:madeOf 최소 1개 · 최대 1개 · 클래스 cmdm:Material 경고 부품 재질이 지정되지 않았습니다.

cmdmsh:AssemblyShape

NodeShape

대상 클래스 cmdm:AssemblyDefinition

경로조건수준메시지
cmdm:hasBOMLine 최소 1개 위반 조립품은 BOM 라인이 1개 이상 필요합니다.

cmdmsh:BOMLineShape

NodeShape

대상 클래스 cmdm:BOMLine

경로조건수준메시지
cmdm:bomParent 최소 1개 · 최대 1개 · 클래스 cmdm:AssemblyDefinition 위반
cmdm:bomChild 최소 1개 · 최대 1개 · 클래스 cmdm:ItemDefinition 위반
cmdm:quantity 최소 1개 · 최대 1개 · 형식 xsd:positiveInteger 위반

위반 BOM 순환 참조: 하위 아이템이 상위 아이템을 포함합니다.

SPARQL 보기
SELECT $this WHERE {
  $this cmdm:bomParent ?p ; cmdm:bomChild ?c .
  ?c (cmdm:hasBOMLine/cmdm:bomChild)* ?p .
}

cmdmsh:MassPropertyShape

NodeShape

대상 클래스 cmdm:PartDefinition

경고 표면적이 부피 대비 물리적으로 불가능하게 작습니다(질량 특성 재계산 필요).

SPARQL 보기
SELECT $this ?value WHERE {
  $this cmdm:volume ?v ; cmdm:surfaceArea ?value .
  FILTER ( (?value * ?value * ?value) < 113.0973 * ?v * ?v * 0.999 )
}

cmdmsh:FastenerSizeShape

NodeShape

대상 클래스 cmdm:Fastener

경고 아이템 코드의 나사 규격과 품명/규격 속성이 다릅니다.

SPARQL 보기
SELECT $this ?value WHERE {
  $this cmdm:itemCode ?code ; cmdm:partName ?value .
  FILTER ( regex(?code, "M[0-9]+X[0-9]+") && regex(?value, "M[0-9]+X[0-9]+") )
  BIND ( replace(?code, "^.*(M[0-9]+X[0-9]+).*$", "$1") AS ?a )
  BIND ( replace(?value, "^.*?(M[0-9]+X[0-9]+).*$", "$1") AS ?b )
  FILTER ( ?a != ?b )
}

cmdmsh:RobotSystemShape

NodeShape

대상 클래스 cmdm:RobotSystem

경로조건수준메시지
cmdm:hasArm 최소 1개 · 최대 1개 위반
cmdm:hasController 최소 1개 · 최대 1개 위반

위반 V15: 컨트롤러와 로봇 암의 보정 데이터 페어링이 필요합니다 (에러 E-7712).

SPARQL 보기
SELECT $this WHERE {
  $this cmdm:hasArm ?arm ; cmdm:hasController ?ctl .
  ?arm cmdm:instanceOfModel/cmdm:code "V15" .
  FILTER NOT EXISTS { ?arm cmdm:pairedWith ?ctl }
}

위반 로봇 모델이 지원하지 않는 설치 유형입니다(예: V15는 바닥·천장만 가능).

SPARQL 보기
SELECT $this ?value WHERE {
  $this cmdm:hasArm/cmdm:instanceOfModel ?m ; cmdm:hasMountingType ?value .
  FILTER NOT EXISTS { ?m cmdm:supportedMounting ?value }
}

위반 컨트롤러 모델이 로봇 모델의 지정 컨트롤러와 다릅니다.

SPARQL 보기
SELECT $this ?value WHERE {
  $this cmdm:hasArm/cmdm:instanceOfModel ?m ; cmdm:hasController/cmdm:instanceOfModel ?value .
  FILTER NOT EXISTS { ?m cmdm:usesControllerModel ?value }
}

SELECT $this WHERE {
  $this cmdm:limitsJoint ?j .

  FILTER ( (bound(?lo) && ?lo < ?hwMin) || (bound(?hi) && ?hi > ?hwMax) )
}

  FILTER ( ?value > ?max )
