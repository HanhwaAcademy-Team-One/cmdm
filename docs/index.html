가상 데이터 고지

예시로 쓰인 제품군(VORLA 시리즈, 모델 V4·V7·V15), 컨트롤러, 운영 SW, 에러 코드, 도면번호, 아이템 코드, 수치 제한값, 매뉴얼 절 번호는 모두 이 프로젝트에서 만든 가상 값이며 실제 제품·회사와 관련이 없습니다. 이 사이트는 교육 목적의 비상업 프로젝트입니다.
